Información sobre ecuaciones cuadráticas

Una ecuación cuadrática es una ecuación de segundo grado que tiene la forma:

ax² + bx + c = 0

Donde a, b y c son coeficientes reales, y a ≠ 0.

Fórmula cuadrática

La solución de una ecuación cuadrática se obtiene mediante la fórmula:

x = [-b ± √(b² - 4ac)] / (2a)

Discriminante

El discriminante (D) determina la naturaleza de las soluciones:

  • D > 0: La ecuación tiene dos soluciones reales distintas.
  • D = 0: La ecuación tiene una solución real doble.
  • D < 0: La ecuación tiene dos soluciones complejas conjugadas.

Cómo usar esta herramienta

1. Ingresa los valores de los coeficientes a, b y c en los campos correspondientes.

2. Haz clic en "Calcular soluciones" para resolver la ecuación.

3. Revisa los resultados que incluyen el discriminante y las soluciones.

4. Si el discriminante es negativo, se mostrará el mensaje "La solución es compleja".

Ejemplo: Para 2x² - 4x - 6 = 0

a = 2, b = -4, c = -6

D = (-4)² - 4(2)(-6) = 16 + 48 = 64

D > 0, entonces tiene dos soluciones reales:

x₁ = [4 + √64] / 4 = [4 + 8] / 4 = 3

x₂ = [4 - √64] / 4 = [4 - 8] / 4 = -1
